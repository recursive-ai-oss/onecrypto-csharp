# RecursiveAI.OneCrypto

Cryptography (not cryptocurrency) for .NET, written from the specifications on the base class library alone: ASN.1, CMS, RFC 3161 time-stamps, X.509, and the primitives the platform lacks. It is unaffiliated with other products named OneCrypto.

This is an early preview. It is not yet independently audited.
